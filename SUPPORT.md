# Support

ABE is maintained by volunteers and staff of a nonprofit program, alongside other work. Help is best effort, with no guaranteed response time.

## Where to get help

| You want to | Go here |
|-------------|---------|
| Deploy, configure or fix a deployment | The [README](README.md): [Quick start](README.md#quick-start), [Configuration](README.md#configuration) and [Troubleshooting](README.md#troubleshooting). Also [docs/custom-domain.md](docs/custom-domain.md) and [docs/data-ingestion-s3-and-sync.md](docs/data-ingestion-s3-and-sync.md). |
| Ask a question, or ask how something works | [Discussions, Q&A](https://github.com/The-Burnes-Center/abe/discussions/categories/q-a). Search first: your question may already be answered. |
| Suggest an idea | [Discussions, Ideas](https://github.com/The-Burnes-Center/abe/discussions/categories/ideas) |
| Report a bug you can reproduce | [Open an issue](https://github.com/The-Burnes-Center/abe/issues/new/choose) with the bug report form. Include the release or commit, region, steps and logs, with account IDs and private content removed. |
| Report a security vulnerability | [Private vulnerability reporting](https://github.com/The-Burnes-Center/abe/security/advisories/new). Never in a public issue or Discussion. See [SECURITY.md](SECURITY.md). |
| Report a Code of Conduct concern | See [MAINTAINERS.md](MAINTAINERS.md) and [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). |
| Contribute a fix | [CONTRIBUTING.md](CONTRIBUTING.md) |

Issues are for confirmed bugs and planned work. Questions opened as issues will be moved to Discussions.

## Out of scope

The maintainers cannot help with:

- Billing, quotas, account limits or permissions problems in your own AWS account. Contact AWS Support for those. The README's [Costs](README.md#costs) section gives estimates only.
- Forks with heavy changes. We can look at a problem if you reproduce it on an unmodified release, but we cannot debug your changes.
- Choosing documents, writing prompts or judging answer quality for your organization's use case.
- Running or securing your deployment for you. The [security model](README.md#security-model) describes what the stack does and does not cover.

## Response expectations

- Replies come when a maintainer has time. A few days is common, and some weeks will be slower.
- Security reports sent through private reporting are handled first. The targets in [SECURITY.md](SECURITY.md) apply.
- Only the latest release and `main` are supported.
- There is no SLA, no paid support and no guarantee that a bug will be fixed or a feature built. Pull requests are the fastest way to get a change made.

You can help others too: answering a question in Discussions is a contribution.
